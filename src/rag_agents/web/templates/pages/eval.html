make eval AGENT={{ agent.agent.slug if agent else "tolstoi" }} DATASET=tolstoy CONFIG=dense   # ~25 мин, ~$0.25
make eval AGENT=… LIMIT=5 JUDGE=0                                  # быстрый прогон без судьи

Датасеты — eval/datasets/*.jsonl, конфигурации — configs/eval/*.yaml (ARCHITECTURE §15).
